# 던전 위에서 본 지도 (data/dgmap · data/guides/dungeon-maps3d.json)

포에버 클라이언트에서 wow.export(v0.2.21)로 던전 모델을 내보내 위에서 본 그림을 만든다. 게임 파일은 저장소에 넣지 않고 결과 그림(webp)과 좌표만 올림.

1. wow.export Maps 탭
   - 새 엔진 던전 지도(지형 칸이 있는 것: 죽음의 폐광·그림자송곳니·가시덩굴 우리·구릉·수도원 등): 칸 전부 선택(Ctrl+A) → Export OBJ. 칸마다 `adt_X_Y_ModelPlacementInformation.csv`에 WMO 자리(PositionX/Y/Z, RotationY).
   - WMO 하나짜리 지도(통곡의 동굴·지하감옥·심연·놈리건·울다만·가라앉은 사원 등): Export Global WMO. 자리 = (17066.67, 0, 17066.67), 회전 0.
   - 내보내기 설정: Export WMO만 켬(WMO Sets·M2 끔: 빠르고 위에서 볼 때 상관없음).
2. 좌표(실측, 몹 자리로 확인 — 몹 89~100%가 바닥 3야드 안):
   - 모델 OBJ (x,y,z) → 모델 좌표 (x, −z, y), Z 위
   - 세계 = R(RotationY + 180°) · 모델 + (17066.67 − PosZ, 17066.67 − PosX, PosY)
   - 지형 OBJ (x,y,z) = (세계Y, 세계Z, 세계X)
   - 도우미: `texneed.py parts/<던전>.json` → 아직 안 가져온 텍스처 경로 목록, `autoparts.py <slug> <maps 폴더> <칸들> <WMO 정규식>` → 지형 칸+WMO 설정 만들기.
3. `prep.py parts/<던전>.json` → 세계 좌표 정점·텍스처 묶음 (skiptex로 지붕·LOD·덩굴 뺌)
4. `make.py <slug>` (conf.json: 층마다 높이 범위) → render.html(WebGL, 헤드리스 크롬)로 위에서 본 직교 투영. 아래를 보는 면(천장)과 층 높이 위는 버림. 지형은 먼저 깔고 건물을 위에.
   - 층 설정: z(높이 범위)·above/below(위아래로 더 보일 높이)·pad·box(세계 x,y 범위 직접)·clip(같은 높이에 다른 구역이 겹칠 때 이 층 구역만: 검은바위 첨탑 아래/위, 검은바위 나락 3구역, 혈투의 전장 동·북·서, 마라우돈 바깥/안쪽, 스트라솔름 정문/뒷문).
   - 핀: 보스 이름이 CMaNGOS(classic-db) 몹과 같으면 그 자리(w=1). 영어 이름이 없으면 한글 이름(· 로 나뉜 것 중 하나, 3곳 이하인 NPC)으로도 찾음. 아니면 예전 wowf.io 지도 핀을 그 층 보스 2곳 이상으로 맞춘 1차식으로 옮김(w=2, 점선).
   - 쫄 무리·순찰: /tmp/cmout/packs.json(tools/mobs) 세계 좌표 → 그림 %.
   - 그림 다듬기(post.py): 조금 밝게 + 바깥 가장자리 어두운 테두리 + 그 바깥 은은한 빛.
   - render.html은 색 그림과 함께 높이 그림(_h: 가장 낮은 위쪽 면 = 바닥, 문틀·들보에 안 막힘)과 기울기 그림(_n: 위에서 보이는 면이 벽인지)을 같이 저장.
4-1. `nav.py <slug> …` (make.py 다음): 바닥 높이로 칸 그래프(이웃 높이 차 1.3야드 안, 벽 칸 막음, 작은 틈은 비싸게 건넘)를 만들고 입구 → 보스 순서로 걷는 길을 찾음(scipy dijkstra). 길에서 9야드 안 무리를 길 순서대로 풀로 묶음(첫 무리에서 38야드 또는 13마리 넘으면 새 풀) → 층 route, 무리 p[i][10] = 풀 번호(던전 전체 이어 셈, 0 = 옆길). 바닥 밖에 떨어진 대략 핀(w=2)은 뺌.
   - 풀 번호는 추정(공략 판 기록 아님). 워크래프트로그 대표 판 자료가 생기면 그걸로 바꿀 것.
5. `combine.py` → data/dgmap/*.webp + data/guides/dungeon-maps3d.json. 미리보기만 이 파일을 따로 받아 dungeon-guide.json 던전마다 f3로 붙임(실제 앱 자료에는 안 넣음), 미리보기에서 「위에서 본 지도 / 예전 지도」로 바꿔 봄.

`NOSHOT=1 make.py …`: 그림은 그대로 두고 핀·쫄만 다시 계산(/tmp 원본 그림 재사용).

만든 던전(26): 통곡의 동굴, 죽음의 폐광, 그림자송곳니, 지하감옥, 검은심연, 가시덩굴 우리, 놈리건, 붉은십자군 수도원 4곳, 가시덩굴 구릉, 울다만, 줄파락, 가라앉은 사원, 성난불길 협곡, 마라우돈, 검은바위 나락, 검은바위 첨탑 아래·위, 혈투의 전장 동·북·서, 스칼로맨스, 스트라솔름 정문·뒷문. 포에버 전용 던전(달라란·드워프 발굴지 등)은 CMaNGOS 자리 자료가 없어 예전 지도만.
