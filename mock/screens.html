홈 · 장비 · 던전 시안

개추(47 수양 사제)로 뽑은 실제 앱 자료예요. 시안마다 세 화면이 이어져 있어요. 파란 번호를 누르면 다른 화면의 같은 곳이 빛나요. 폰으로 열면 앱처럼 한 화면씩 써 볼 수 있어요.

A · 게임 창

와우 안의 창처럼: 모험 안내서 · 캐릭터 창 · 던전 도감. 양피지와 금테를 가장 많이 씀.

홈
카드 여러 장 → 「모험 안내서」 창 하나(오늘·마을·지난 기록 탭)
장비
목록 → 캐릭터 창 인형, 칸마다 +점수·레벨
던전
긴 스크롤 → 던전 도감(우두머리 옆에 노릴 템)

이어진 곳

  1. 바꿀 템 「주만자 장갑 +13」: 홈 → 장비 손 칸 → 던전 줄파락
  2. 던전 「마라우돈」: 홈 → 던전 → 장비 「49레벨 주장비 +23」
  3. 던전 가기 전 퀘스트 6: 홈 → 던전 준비

PC에서는 세 창을 나란히 띄워 둠(안내서 | 캐릭터 | 도감).

B · 지금 할 일

화면마다 맨 위 한 장이 「지금 할 것」. 전문기술 창과 같은 방식이라 손에 익은 모양.

홈
맨 위 「지금」 한 장 + 다음 할 것 네 칸
장비
바꿀 것 순서대로 → 레벨 오르면 → 끼고 있는 것
던전
「이번 던전 준비」 1~4단계

이어진 곳

  1. 바꿀 템 「주만자 장갑 +13」: 홈 → 장비 손 칸 → 던전 줄파락
  2. 던전 「마라우돈」: 홈 → 던전 → 장비 「49레벨 주장비 +23」
  3. 던전 가기 전 퀘스트 6: 홈 → 던전 준비

PC에서는 왼쪽에 「지금」 카드를 고정, 오른쪽에 나머지 카드.

C · 레벨 길

모든 화면을 레벨 줄(47 → 50)로 묶음. 언제 무엇을 바꾸고 어디 가는지 레벨로 한 번에.

홈
47→50 레벨 길 위에 할 일
장비
레벨마다 바꿀 템을 묶음
던전
레벨 띠에서 던전 고르기 + 레벨별 템·퀘스트

이어진 곳

  1. 바꿀 템 「주만자 장갑 +13」: 홈 → 장비 손 칸 → 던전 줄파락
  2. 던전 「마라우돈」: 홈 → 던전 → 장비 「49레벨 주장비 +23」
  3. 던전 가기 전 퀘스트 6: 홈 → 던전 준비

PC에서는 위에 레벨 길 한 줄을 고정하고 아래 세 칸.

시안이라 눌러도 실제 기록은 안 바뀌어요 · 화면 안은 위아래로 밀어 볼 수 있어요
