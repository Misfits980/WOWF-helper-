홈 · 장비 · 던전 시안

개추(47 수양 사제)로 뽑은 실제 앱 자료예요. 시안마다 세 화면이 이어져 있어요. 파란 번호를 누르면 다른 화면의 같은 곳이 빛나요. 폰으로 열면 앱처럼 한 화면씩 써 볼 수 있어요.

A · 금테 창

지금 고르신 쪽. 와우 안의 창처럼 모험 안내서 · 캐릭터 창 · 던전 도감, 양피지와 금테.

홈
카드 여러 장 → 「모험 안내서」 창 하나(오늘·마을·지난 기록 탭)
장비
목록 → 캐릭터 창 인형, 칸마다 +점수·레벨
던전
긴 스크롤 → 던전 도감(우두머리 옆에 노릴 템)

이어진 곳

  1. 바꿀 템 「주만자 장갑 +13」: 홈 → 장비 손 칸 → 던전 줄파락
  2. 던전 「마라우돈」: 홈 → 던전 → 장비 「49레벨 주장비 +23」
  3. 던전 가기 전 퀘스트 6: 홈 → 던전 준비

PC에서는 세 창을 나란히 띄워 둠(안내서 | 캐릭터 | 도감).

D · 클래식 창

와우 클래식 그대로의 돌 테두리 창 · 왼쪽 위 동그란 초상화 · 빨간 단추 · 창 아래 탭.

홈
와우 퀘스트 일지처럼: 위 목록(난이도 색) + 아래 양피지 설명
장비
클래식 캐릭터 창 + 「현재 착용 / 새 템」 비교 툴팁 두 장
던전
던전 찾기 창: 던전 고르고 → 우두머리·노릴 템·퀘스트

이어진 곳

  1. 바꿀 템 「주만자 장갑 +13」: 홈 → 장비 손 칸 → 던전 줄파락
  2. 던전 「마라우돈」: 홈 → 던전 → 장비 「49레벨 주장비 +23」
  3. 던전 가기 전 퀘스트 6: 홈 → 던전 준비

PC에서는 게임처럼 창 두세 개를 겹치지 않게 펼쳐 둠.

E · 모험 일지

화면 전체가 펼친 책 한 쪽. 장(章)·리본 책갈피·도장 찍은 아이콘으로 일기 쓰듯.

홈
화면 전체가 일지 한 쪽: 오늘 할 일을 체크하는 책
장비
장부 표: 부위 | 지금 | 바꿀 것 | +점수
던전
던전 기록장: 우두머리 목록에 템 도장

이어진 곳

  1. 바꿀 템 「주만자 장갑 +13」: 홈 → 장비 손 칸 → 던전 줄파락
  2. 던전 「마라우돈」: 홈 → 던전 → 장비 「49레벨 주장비 +23」
  3. 던전 가기 전 퀘스트 6: 홈 → 던전 준비

PC에서는 책을 두 쪽으로 펼쳐 왼쪽 목록 · 오른쪽 내용.

F · 게임 화면

게임하면서 보는 화면처럼 미니맵 · 퀘스트 추적기 · 템 알림 · 주사위 창.

홈
게임 화면 그대로: 미니맵 · 퀘스트 추적기 · 템 알림
장비
「바꿀 템 가방」 칸 + 비교 툴팁
던전
던전 지도 + 우두머리 추적기 + 주사위 굴리는 템 창

이어진 곳

  1. 바꿀 템 「주만자 장갑 +13」: 홈 → 장비 손 칸 → 던전 줄파락
  2. 던전 「마라우돈」: 홈 → 던전 → 장비 「49레벨 주장비 +23」
  3. 던전 가기 전 퀘스트 6: 홈 → 던전 준비

PC에서는 게임 화면처럼 가장자리에 미니맵·추적기, 가운데는 비워 둠.

시안이라 눌러도 실제 기록은 안 바뀌어요 · 화면 안은 위아래로 밀어 볼 수 있어요
